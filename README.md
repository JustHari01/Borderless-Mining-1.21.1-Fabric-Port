# Borderless Mining — Unofficial 1.21.1 Fabric Port

This is a community compatibility port of [Borderless Mining by comp500](https://github.com/comp500/BorderlessMining) for Minecraft 1.21.1 on Fabric. It is not affiliated with or endorsed by the original author.

## Features

- Borderless fullscreen that stays visible when you switch to another monitor or application.
- A Borderless Windowed toggle in Video Settings.
- Optional configuration screen through Mod Menu, including monitor selection and custom window dimensions.
- Client-side only; servers do not need the mod.

## Compatibility

- Minecraft 1.21.1
- Fabric Loader 0.16.10 or newer
- Fabric API (the packaged Fabric resource loader module is included)
- Mod Menu 11.0.5 or newer is optional and enables its configuration screen.

The source is based on the upstream 1.20 branch and retains the original MIT license and copyright notice. The port and compatibility edits are by JustHari01.

AI assistance was used to help adapt the source for Minecraft 1.21.1; the release source and mixin targets are being reviewed and built locally.
